# Day 01 — 10 Nov 2026: Kenalan Ads Manager

Today I learned the basic structure of Meta advertising:

- **Campaign** — the goal / objective. One campaign = one purpose.
- **Ad Set** — who sees it and where: audience, placement, budget, schedule.
- **Ad** — what people actually see: creative, copy, link / CTA.

Notes in my own words:
- If the campaign objective is wrong, a good ad still works against the wrong goal.
- Budget lives at Ad Set level in the basic setup, so audience testing = Ad Set testing.
